# pairwise-hrtf-spatial

戴上耳机，背后脚步听起来在正前方，转身后声音突然跳到左耳，穿过门后低频全没了：HRTF 数据集按方位角最近邻取，仰角和背后方位共用一个样本；双耳坐标转换把 UE 的左手坐标系直接喂给右手系卷积器，前后和左右整体镜像；头追延迟没补偿，转头后声像滞后几十毫秒；近场声源仍用远场 HRTF，贴耳说话没有距离感；遮挡只查一条射线，门框挡住直达声却漏掉门缝衍射；遮挡滤波把低频也一起砍掉，隔门声音像被掐断；卷积分块大小和采样率绑定，切到 48kHz 后块长变化，尾部出现周期性咔哒；多声道输出按固定顺序写，设备通道布局不同时左右声道互换；HRTF 数据集之间没有插值，转头经过两个方位时声像跳变；混响发送在干声之后又叠了一次 HRTF，背后声源被前置；手机和 PC 的 HRTF 数据集不同但缓存共用，换设备后音色突变；声源和听者坐标每帧更新，音频线程读到撕裂的位置；动态范围压缩在双耳化之后做，左右声道联动导致声像塌陷。audio/hrtf_spatial.py 是核心，tests/test_hrtf_spatial.py 15个红。要修的是：方位插值；坐标转换；头追补偿；近场模型；多射线遮挡；低频保留；分块自适应；通道布局；数据集插值；混响顺序；设备缓存；线程同步；双耳压缩。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
